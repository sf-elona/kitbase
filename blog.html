A spacing scale you can defend in a design review

Eyeballing margins falls apart the moment someone asks "why 13 pixels?". A 4-point base with a fixed set of steps (4, 8, 12, 16, 24, 32, 48, 64) gives you an answer every time — and a token file you can hand to engineering.
