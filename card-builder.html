Workflow
How to actually ship a new template

      
    
        
  1. 1. Design the page
    Write the new template's own HTML file (copy the closest existing one, e.g. bloom-hero.html, as a starting point) or ask Claude to build it. Save it in this same folder.
    2. 
        
  2. 2. Fill this form
    Match the title, description, price and thumbnail to what you just built. Watch the preview on the right until it looks right.
    3. 
        
  3. 3. Copy the grid code
    Click "Copy code" above the first code block.
    4. 
        
  4. 4. Paste it into templates.html
    Open templates.html, find <div class="grid">, and paste the new <article> block anywhere inside it — order doesn't matter, newest first is common.
    5. 
        
  5. 5. If it's a paid item, add the Buy button
    Once you have a Lemon Squeezy checkout link for the product, paste it into the "Buy link" field, copy the second snippet, and paste it into the template's own page.
    6. 
        
  6. 6. Save and publish
    If you're working with Claude Code, just say "commit and push this" — that's it. Working directly on GitHub? Edit the files at github.com/sf-elona/kitbase in the browser (pencil icon on each file) and commit — GitHub Pages redeploys automatically in about a minute.
    7.
